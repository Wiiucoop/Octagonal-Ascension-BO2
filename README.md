# Octagonal-Ascension-BO2
Black ops 2 Zombies Custom Map

![IMAGE](https://i.ibb.co/ymTGzS8n/Design-sem-nome-20260827-023246-0000.png)

##BETA 1 RELEASE!!!!!

This is a remake from a custom zombies map "Octagonal Ascension", it is a very popular map that originally relesed back in WaW and also Bo3. Some may argue its a port, but this was actually made using the custom map template instead, so in reality only the map model itself was ported directly.

ATTENTION! this is a challenging map, so you have to be prepared!

Features: 

- Buyable ending ($50k)
- A lot of perks (Including PHD, Electric Cherry, Whos who, Amm-O-Matic)
- Tranzit super sprinters for increased difficulty
- Boss zombie (fire zombie, acts like napalm)
- Constantly spawning zombies
- Increased horde size from 24 to 32 (buggy)
- More Powerups (Zombie Blood, Deathmachine etc.)

Known Limitations:

- There is an invisible guardrail around the entire maps, this is to reduce the amount of zombies falling through the map while chasing the player.

**DOWNLOAD:**

* Download zm_octagonal.zip from [this github release](https://github.com/Wiiucoop/Octagonal-Ascension-BO2/releases/latest).
* Navigate to the %LocalAppData%\Plutonium\storage\t6\mods folder, if the mods folder doesn't exist you will have to create it.
* Extract the contents of zm_octagonal.zip into your mods folder.
* Load the mod from the main menu.
* To play, select the new button "Play Octagonal SOLO" or "Play Octagonal CO-OP"
